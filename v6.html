통근 시뮬레이션

부부합 = 나 + 아내 편도 · 표의 ‘합’ 열은 앞=나, 뒤=아내

단지별 통근 시간

‘나’는 위에서 고른 회사 기준, 시간 아래 작은 글씨는 자동차 거리입니다. ‘부부합’은 나+아내 편도 합계, 아래 작은 숫자는 현재집보다 줄어드는(−)·늘어나는(+) 분입니다. 맨 위 줄은 현재집입니다. 행을 누르면 아래에 상세 경로와 지도 링크가 나옵니다. 열 제목을 누르면 정렬됩니다.

자금 설정 · 호가 캡처(원본 이미지 포함) · 관심 단지 · 현실 후보 · 메모 · 체크리스트를 내 구글 시트(숨김 탭 NewHome_Sync)와 구글 드라이브(NewHome_캡처 폴더)에 저장해 모든 기기에서 같이 씁니다. 화면 모드처럼 기기마다 다른 설정은 그대로 둡니다.

처음 한 번 설정하기 (PC에서)
① ‘2026 주식 포트폴리오 통합본’ 시트 → 확장 프로그램 → Apps Script
② 기존 코드를 모두 지우고 아래 코드를 붙여넣기 → 저장 (즉시가용 자산 L16 불러오기 기능도 그대로 들어 있습니다)
③ 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포 (주소가 그대로 유지됩니다). 처음 배포라면 ‘새 배포 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자’. 드라이브 권한을 묻으면 허용
④ 웹 앱 주소를 위 칸에 넣고 ‘동기화 켜기’ → ‘지금 동기화’
⑤ 휴대폰: 앱의 더보기 → 이 화면에서 같은 동기화 코드와 웹 앱 주소를 넣고 ‘동기화 켜기’ (PC의 코드는 위 칸에서 복사해 카톡 등으로 보내면 편합니다)
동기화 코드는 비밀번호 역할입니다. 코드를 모르면 주소만으로는 데이터를 읽거나 바꿀 수 없습니다.
